# Bibot Discord Dice Bot

A Discord bot that can roll dice for:

-   Powered By The Apocalypse (MoTW and PbtA)
-   FATE
-   GURPS
-   Mistborn Adventure Game
-   [3 Raccoons in a Trench Coat](https://penguinking.com/three-raccoons-in-a-trenchcoat/)
-   Dark Heresy
-   FACET (a system created by my wonderful husband!)
-   other

It can also draw cards and random fortunes!

## Usage Instructions

### Requirements:

-   random.org API key
-   Discord bot token

### How To Run:

1. npm install
2. npm start (or run start.sh)
